# Creator Center 1.5

1.5 期静态交互原型，包含账号登录／注册流程与创作者工作台。

- 仓库：https://github.com/alinaskyliu-hub/creator-center-1-5
- 网站：https://alinaskyliu-hub.github.io/creator-center-1-5/

- `account_aurora/`：登录、注册和账号找回。
- `StudioDemo/`：内容管理、数据分析、内容编辑和账号设置。
- 根目录 `index.html`：自动进入账号登录页。

项目使用原生 HTML、CSS 和 JavaScript，无需构建。
